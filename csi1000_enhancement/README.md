## 回测口径

上一交易日收盘后，使用当日信号与风险数据确定次日目标；次日按全天VWAP（成交额÷成交量）模拟成交。旧仓计至VWAP，新仓仅计VWAP成交后收益，统一按收盘估值。停牌或无有效VWAP时不交易，全天封涨停不买、全天封跌停不卖；卖出限于原有持仓，现金不足时缩减买入。目标约束不代表成交后或收盘权重始终满足，价格漂移可能略超2%。基准为中证1000价格指数，图中同时列示相对全收益指数的超额。

日线VWAP模拟不包含分钟容量、排队及额外冲击成本。历史已统一按此口径重算。

超额累加为每日扣费收益减基准收益后求和；年化净超额为该日均差额乘252；超额夏普（IR）为日均差额除以其标准差再乘√252。相对回撤按策略净值/基准净值计算。日均单边换手=(买入比例+卖出比例)/2；费用按买卖合计分别扣收，不重复计费。
